this is my cipher calculator
You may be asking what is that?
Well a cipher is a secret code, there are many different ciphers, for example i used the vigenere cipher, which is a cipher that takes your message, and a code word. Once the code word and your message have been acquired you have to match up the word with the code word for example meet me at the beach, with the code word apple would be, appl ea pp lea pplea, than you would put that under the word and change the message by the positions of the code word and the position of the letters in the message. Once you complete those steps you now have an encrypted text!
