## Instructions

### Getting Started

1. Open the Cipher Calculator.
2. You will start on the main screen.
3. Use the **left and right arrow buttons** to move between different screens.

   * The **right button** moves forward to the next screen.
   * The **left button** moves back to the previous screen.
4. Use the buttons on each screen to access different features.

---

## Navigating the Screens

* Use the **right arrow button** to explore the different features of the Cipher Calculator.
* Use the **left arrow button** to return to previous screens.
* Continue using the arrow buttons until you find the feature you want to use.

Available features include:

* Calculator
* Encrypt
* Decrypt
* Voice Recorder
* Other tools

---

## How to Encrypt a Message

1. Use the arrow buttons to navigate to the **Encrypt** screen.
2. Enter the message you want to hide.
3. Enter your code word. This will be used as the key for the Vigenère cipher.
4. Press the **Encrypt** button.
5. Your message will now be changed into encrypted text.

Important:

* Remember your code word because you will need the same one to decrypt your message.
* Using a different code word will make the message decrypt incorrectly.

---

## How to Decrypt a Message

1. Use the arrow buttons to navigate to the **Decrypt** screen.
2. Enter the encrypted message.
3. Enter the same code word used during encryption.
4. Press the **Decrypt** button.
5. Your original message will appear.

---

## How to Use the Voice Recorder

1. Use the arrow buttons to navigate to the **Voice Recorder** screen.
2. Allow microphone access if your device asks for permission.
3. Press the **Record** button to start recording.
4. Press the **Stop** button when you are finished.
5. Your recording will be saved.

---

## How to Use the Calculator

1. Use the arrow buttons to navigate to the **Calculator** screen.
2. Enter numbers using the calculator buttons.
3. Choose the operation you want to use.
4. Press the equals button to see your answer.

---

## Tips

* Use the left and right buttons to move through the different screens.
* Make sure you enter your message and code word correctly.
* Encryption and decryption require the same code word.
* Make sure microphone permissions are enabled for the voice recorder.
